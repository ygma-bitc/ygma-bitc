# Yaoguang Ma

Clinical programmer working on interactive reporting for clinical trials: **teal** modules, **Shiny**, and CDISC **ADaM**.

## Open source

### [tm.hyslaw](https://github.com/ygma-bitc/tm.hyslaw)

Docs: https://ygma-bitc.github.io/tm.hyslaw/

Teal modules and reusable builders for exploratory **Hy's Law** monitoring and **eDISH** plots from `ADSL` and `ADLB`. Table and plot builders run without Shiny; teal modules are optional. This is a review aid, not a submission TFL.

### [tm.ttni](https://github.com/ygma-bitc/tm.ttni)

Docs: https://ygma-bitc.github.io/tm.ttni/

Teal module and table builder for **time to next intervention (TTNI)** and related time-to-event endpoints: Kaplan–Meier summaries, landmark rates, and a hazard ratio when the study has two arms.

## Stack

R · teal · tern · Shiny · CDISC ADaM · SAS · Python
